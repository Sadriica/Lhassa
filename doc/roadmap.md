# Lhassa implementation plan

**Archived.** This was the pre-brain implementation plan (cost/correctness
core, durability, MCP, orchestration, local voice) written when Lhassa was
still framed as a general-purpose voice product to extend, rather than the
identity-first brain it became. It has been superseded by the phase-by-phase
build that actually happened.

For what Lhassa is today and where it's going, read:

- [`lhassa-brief.md`](lhassa-brief.md) — the living spec, organized by phase.
- [`decisions.md`](decisions.md) — the phase-by-phase decisions log, the
  source of truth for what was actually built and why.

Kept here for archaeology only — do not treat anything below this line
(there is nothing below this line) as a current plan.
